# Part III — UML Reading Questions

Given:

```text
Customer 1 -------- 0..* Order

Order 1 ◆----------- 1..* OrderLine

OrderLine * -------- 1 Product
```

Answer:

1. Can a customer exist with zero orders?
2. Can an order exist with zero order lines according to the model?
3. Can the same product appear in multiple order lines?
4. Does an order line own a product?
5. Which relationship shows the strongest ownership?
6. If a product is removed from one order, should the product disappear from the catalog?
